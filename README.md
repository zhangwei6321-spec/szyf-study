# 河南三支一扶 · 上岸备考学习网

基于《重考最新2026年河南三支一扶资料包》整理的一站式备考学习网站，**纯静态、无需联网、无需安装**，双击 `index.html` 即可在浏览器中打开使用。

🔗 **在线访问：<https://zhangwei6321-spec.github.io/szyf-study/>**（手机浏览器直接打开，进度存在本机）


## 使用方法

1. 直接双击 `index.html`，或用浏览器打开它；
2. 学习进度、错题本、掌握情况都会**自动保存在本地浏览器**（localStorage），下次打开继续。

> 建议使用 Chrome / Edge 等现代浏览器。手机也能用，直接发送 `index.html` + 同目录文件即可（建议整个文件夹一起拷贝）。

## 刷题分类方式

- **真题按年份**：2013、2015—2025 年真题各成一组（12 个年份分组）；
- **公基练习题按内容**：法律（法理学/宪法/刑法/民法/行政法/诉讼法/商经法）、公文、经济、政治、行政管理、人文历史、科技、地理共 **45 个章节分组**，想补哪块刷哪块；
- 冲刺卷、会议自测、时政模拟、不定项各自独立分组。

## 题库数据来源（7520 题）

- **真题**：2013—2025 年共 13 个年份（2014 年收录 98 题：单选40+多选29+不定项29）
- **冲刺卷**：2026 年河南省三支一扶笔试考前冲刺卷（一/二/三）
- **公基练习题**：第一/二/三册全量收录（OCR 识别扫描版，题目+解析，约 5740 题）
- **会议自测**：二十大报告自测题、二十届三中全会 40 题、二十届四中全会 30 题、纪委四次全会、十五五规划 260 题
- **时政模拟**：2026 年 7 月时政模拟题（120 题）
- **不定项练习**：2026 年三支不定项预测题（1/2/3）

## ✅ 答案质量三重校验（保证不出现错误答案）

1. **题型一致性**：单选题答案必须是单个字母、多选题为多字母、判断题为"正确/错误"，违规即剔除；
2. **答案-选项范围**：答案字母必须落在实际选项范围内，选项缺失/残缺的题目一律剔除（不展示无法作答或可能错误的题）；
3. **解析交叉验证**：答案与解析中的结论（"故正确答案为X""A、B项正确"）交叉比对，抽样人工复核全部正确。

校验未通过的 132 道 OCR 残缺题已全部剔除，**题库中的每一道题答案都可信**。

## 构建脚本（可选）

如需重新生成数据，可运行：

```bash
python3 extract_corpus.py       # 从资料包提取文本到 corpus/
python3 ocr_parallel.py         # OCR 扫描件（需先安装 ocr/venv 依赖）
python3 build_data.py           # 生成 questions.js（含三重校验）
python3 build_content.py        # 生成 knowledge/shizheng/koujue/meta.js
```
